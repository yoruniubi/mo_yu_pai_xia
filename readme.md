## ✨ 项目简介

《摸鱼牌侠》是一款基于 **Godot 4.5** 开发的回合制卡牌肉鸽游戏。玩家在战斗中通过打出 Emoji 卡牌组成连招触发强力效果；在 30 关爬塔流程中逐步完成核心卡进化、迎战形态各异的职场怪物，最终挑战 CEO 三头狮。

每局结束都会结算 **局外积分（Meta Points）**，可在主菜单的"摸鱼工坊"中永久升级初始属性、解锁流派天赋与特殊机制，让下一局的摸鱼之路更加丝滑。

项目当前已形成完整可玩的主循环（地图 → 战斗/事件/商店/休息/宝箱 → 进化 → 终局 Boss → 局外升级），并支持 Web 导出与 GitHub Pages 自动部署。

---

## 🎮 核心玩法

- **Emoji 序列连击**：打出的卡牌会进入序列槽，满足配方自动触发 Combo。
- **四名可选角色**：博姆 / 墨里 / 莱奥 / 苏珊，拥有不同核心与专属连招。
- **双重进化系统**：中后期两次进化，形成流派并获得终极手段。
- **职场主题机制**：KPI、早会、虚假目标、文档塞牌、规则审计、外包压价等。
- **节点地图探索**：战斗 / 精英 / 事件 / 商店 / 休息 / 宝藏多种节点。
- **事件关抉择**：随机事件影响 AP、伤害、治疗、卡池与状态。
- **局外永久升级**：用积分解锁资源、策略、特殊三大类共 20+ 项被动天赋。

---

## 🧠 局外升级系统（摸鱼工坊）

通关或战败均可获得 **积分（Meta Points）**，在主菜单进入"摸鱼工坊"消费：

- **资源类**：初始摸鱼力 / 生命值 / 抽牌数 / 多抽多弃。
- **策略类（四大流派）**
  - 摸鱼流：首张减费、手牌丰盈加 AP、回合保留手牌
  - 爆发流：键盘连招追加伤害、加班 0费、低血量增伤
  - 防御流：开局护盾、护盾不清零、护盾抽牌
  - 毒流/Debuff：开局中毒、连招易伤、对中毒目标增伤
- **特殊类**：破罐破摔（半血翻倍）、躺平哲学（无护盾每回合回血）、斜杠青年（每关额外抽角色专属牌）、人脉广泛（商店折扣）、卷王附体（每 5 张牌追加连招检测）等。

升级数据通过 `MetaProgressManager` 单例存档于 `user://meta_progress.cfg`，跨局生效。

## 👾 敌人与 Boss

普通怪物根据节点类型从池中随机抽取，每种都有专属机制，例如：

- **会议树懒**：手牌堆积时增伤，并塞入【无意义早会】。
- **裁员镰鼬**：威胁性削手牌，超员触发"裁员名单"重创。
- **审计猎犬**：每回合发布合规规则，违规追加伤害。
- **薪水小偷浣熊**：偷走 Emoji 序列中的符号。
- **复读鹦鹉**：每回合开局复读上回合最后一个 Emoji。
- **画饼蜘蛛**：持续塞【虚假目标】，每 4 回合"大画饼"。
- **打印机螃蟹**：累计塞卡纸，每 3 张爆发一次。
- **外包秃鹫**：层数越多，AP 越被压低，还会削弱手牌效果值。
- **年终总结鲸**：根据出牌数累积考核压力，超载塞 KPI。
- **监控猿**：监控蓄力，下回合锁定一个 Emoji 槽位。
- **摸鱼猫主管**：抓包出摸鱼卡时惩罚加倍。
- **死线刺猬**：3 回合内未打出 ⌨️ 连招将触发 DEADLINE。
- **KPI 九头蛇**：未在回合内击破指标头则回血。
- **CEO 三头**：狮态 / 羊态 / 蛇态切换，分别施加违规惩罚、伤害上限、AP 封印。

## 🚀 运行方式

### 1) 本地运行（Godot）

1. 安装 **Godot 4.5.x**（建议 4.5.1）
2. 克隆仓库：

```bash
git clone https://github.com/yoruniubi/mo_yu_pai_xia.git
cd mo_yu_pai_xia
```

3. 用 Godot 打开项目目录并运行（主场景为 `Scenes/splash_screen.tscn`）

### 2) Web 版本

仓库已配置 GitHub Actions 自动导出 Web 并部署至 GitHub Pages。  
工作流文件：`.github/workflows/deploy.yaml`
